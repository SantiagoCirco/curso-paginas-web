Paso 2 de 5

💻 ¿Cómo se escribe el código CSS?

Así se ve la estructura real de un Media Query. Usamos la palabra clave @media y agrupamos las reglas especiales entre corchetes { }.

/* 1. Estilos normales para monitores grandes */
body {
  background-color: #0f172a;
}

/* 2. Regla Media Query con sus corchetes { } */
@media (max-width: 600px) {
  /* Todo lo que esté aquí dentro SOLO se aplicará en pantallas chicas */
  body {
    background-color: #7f1d1d;
  }
}
@media Avisa al navegador que aplicará una condición de pantalla.
(max-width: 600px) La condición: "Aplica si el ancho es de 600px o MENOS".
Corchetes { } Contienen los cambios de estilo que se activarán.

Paso 4 de 5

📱 Condiciones del @Media Query

Además de max-width, podemos usar min-width. Esta es la forma profesional preferida porque diseñamos primero para celulares y luego ampliamos.

🔴 max-width (Desktop-First)

Diseñas para monitor y pones reglas para cuando la pantalla se achica.

/* Estilo base: Monitores */
.caja { font-size: 20px; }

@media (max-width: 600px) {
  /* Si es MENOR a 600px */
  .caja { font-size: 14px; }
}

🟢 min-width (Mobile-First)

Diseñas para celular y agregas mejoras cuando la pantalla crece.

/* Estilo base: Celulares */
.caja { font-size: 14px; }

@media (min-width: 600px) {
  /* Si alcanza o SUPERA los 600px */
  .caja { font-size: 20px; }
}
