📦 Paso 1: Form, Fieldset y Legend

<form> envuelve todo el formulario.
<fieldset> crea la caja organizadora.
<legend> le coloca el título justo en el borde superior de la caja. 
<form>
  <fieldset>
    <legend>Perfil del Gamer</legend>

    <!-- Aquí irán los campos -->

  </fieldset>
</form>
💡 Concepto clave:

Agrupar campos ayuda a mantener el formulario ordenado, limpio y comprensible para el usuario.

⚡ Paso 2: La Conexión Label - Input

El atributo for="..." del label debe ser exactamente igual al id="..." del input. 
<label for="gamertag">GamerTag:</label>
<input 
  type="text" 
  id="gamertag" 
  required 
  minlength="3" 
  maxlength="12">
🛡️ Atributos en este código:
  • required: Campo obligatorio.
  • minlength="3" / maxlength="12": Límite de caracteres.

📧 Paso 3: Input Email y Validación

type="email" valida de forma automática que el valor ingresado sea una dirección de correo válida. 
<label for="correo">Correo del Tutor:</label>
<input 
  type="email" 
  id="correo" 
  placeholder="ejemplo@email.com" 
  required>
🛡️ Validación Autoconfigurada:

El navegador exige la presencia del símbolo @ y un dominio (como .com).

📞 Paso 4: Teléfono y Patrón (Regex)

Usa type="tel" y el atributo pattern para definir la regla del formato. 
<label for="telefono">Teléfono:</label>
<input 
  type="tel" 
  id="telefono" 
  pattern="[0-9]{10}" 
  placeholder="1122334455">
🛡️ ¿Qué significa pattern="[0-9]{10}"?
  • [0-9]: Solo permite dígitos numéricos.
  • {10}: Exige exactamente 10 números seguidos.

📝 Paso 5: Textarea (Texto Largo)

<textarea> no usa el atributo type y requiere etiqueta de cierre </textarea>. 
<label for="bio">Estrategia de juego:</label>
<textarea 
  id="bio" 
  rows="4" 
  minlength="10" 
  maxlength="200"></textarea>
🛡️ Atributos en este código:
  • rows="4": Define el alto inicial en líneas.
  • minlength="10": Mínimo 10 caracteres.

🚀 Paso 6: Botón de Envío (Submit)

El atributo value define el texto visible dentro del botón. 
<!-- El botón que dispara el envío -->
<input 
  type="submit" 
  value="🚀 ¡Enviar Formulario!">
💡 Funcionamiento:

Al hacer clic en type="submit", el navegador revisa automáticamente que todos los campos cumplan sus validaciones.
